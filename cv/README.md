# مجلد السير الذاتية

ضع هنا ملفات السير الذاتية (PDF) باسم معرّف المرشح، مثل: `c0032.pdf`.

ثم ضع في حقل «رابط السيرة الذاتية» للمرشح المسار: `cv/c0032.pdf`
(من «لوحة التحكم ← تعديل البيانات»، أو دفعة واحدة برفع ملف Excel فيه عمود «السيرة الذاتية»).

تنبيه: الملفات في هذا المجلد علنية لأي شخص يعرف رابط الموقع أو المستودع.
عند الانتقال إلى OneDrive استبدل المسارات بروابط OneDrive، ثم احذف هذا المجلد.
